# Crime Severity Prediction using Linear Regression and KNN

## Dataset
Indian Crime Dataset (Kaggle)

## Algorithms Used
- Linear Regression
- K-Nearest Neighbors (KNN)

## Results

| Algorithm | MAE | RMSE | R² |
|------------|------------|------------|------------|
| Linear Regression | 1.9323 | 2.3191 | 0.1937 |
| KNN | 1.4721 | 2.0149 | 0.3914 |

## Conclusion

KNN outperformed Linear Regression and was found to be the most suitable algorithm for crime severity prediction.
